# 0001 - 建立 DataHarness 源码教程

## 日期

2026-08-16

## 背景

用户希望学习 C:\projects\research 下的 DataHarness 项目源码。用户对 FastAPI 等技术不熟悉，需要从 Python Web 基础起步的整套教程，要求结合真实代码讲解「项目有哪些功能、如何实现」。

## 决策

1. **教程存放在独立 `tutorial/` 文件夹**（用户请求中的 "toutorial" 按标准拼写为 `tutorial`），而不是默认的 `lessons/`。共享组件（样式、测验 JS）在 `tutorial/assets/`，术语表为 `tutorial/glossary.html`。
2. **课程为 13 课 + 课程首页 + 术语表**，从零基础到端到端实操：
   - 01 项目概览 → 02 Python/Web 基础 → 03 FastAPI API 层 → 04 配置系统
   - 05 领域模型/状态机 → 06 存储层/SQLite → 07 文件导入/检索/快照
   - 08 Agent 基础/工具 → 09 ModelGateway/隐私 → 10 沙箱
   - 11 耐久编排/lease/恢复 → 12 验证门/血缘 → 13 端到端实操
3. **教学法**：每课「概念 → 真实代码引用（文件:行号）→ 练习 → 小测验 → 主源文档推荐」。代码引用全部来自对源码的实地探索（多路 explore agent + 人工抽查关键文件），不依赖记忆。
4. 知识基准为仓库内 `ARCHITECTURE.md` 与 `README.md`；课程中所有「是什么」的论断都带引用。

## 后果

- 用户可独立按顺序自学；每课 10–20 分钟。
- 后续课程扩展应保持「概念 → 代码 → 练习 → 主源」的结构，并继续维护 `tutorial/assets/` 复用组件。
- 已知待办：如用户深入 Agent 定制（加新工具、改提示词），可新增进阶课程并更新本记录。
