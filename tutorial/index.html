DataHarness 源码教程 · 面向零基础

从零读懂 DataHarness：一个 Python Web + Agent 项目的完整解剖

用 13 节课，从一个不懂 FastAPI 的初学者，变成能自己读代码、改代码、跑通全流程的人。

这个课程是什么

DataHarness（C:\projects\research）是一个真实、完整的项目：一个「云端 LLM 驱动、本地持久化、沙箱隔离执行」的数据分析 Agent Harness。 它覆盖了 Python Web 开发（FastAPI）、SQLite 存储、LLM Agent、安全边界等几乎全部后端进阶主题，而且是按生产安全标准写的。 本课程带你结合真实代码一步步读懂它：每个概念都指向仓库里的具体文件和行号，你随时可以打开代码对照。

它到底能干什么？

把数据文件（CSV/Excel/PDF/Word…）导入本地项目 → 由云端大模型理解你的问题 → 模型自动生成 Python/SQL 代码 → 代码在一个断网、只读的沙箱容器里执行 → 结果、图表、结论作为正式产物发布，并附带可验证的证据链。整个过程所有状态都持久化在本地 SQLite 里，任务中断、崩溃都能恢复。

学习路径

建议按编号顺序学习。每课约 10–20 分钟，读完立刻到仓库里对照代码，然后做课末练习。不要跳课——后面的课都依赖前面的概念。

  • 01 项目概览：这个仓库是什么 功能全景、技术栈、目录结构、如何运行。先建立整体地图。
  • 02 Python 与 Web 基础：读懂代码需要的最小知识 类型标注、Pydantic BaseModel、async/await、HTTP 与 Web 服务器是什么。
  • 03 FastAPI 入门：逐行读懂 API 层 路由、中间件、异常映射、请求/响应模型 —— 全部对照 api/app.py 真实代码。
  • 04 配置系统：从 TOML 到 Pydantic Settings config.py 全解：嵌套模型、派生路径、校验、密钥保护。
  • 05 领域模型与状态机：不可变对象如何管状态 frozen 模型、NewType ID、状态转移表、不变量校验。
  • 06 存储层：SQLite、迁移、事务与 CAS 迁移系统、UnitOfWork、仓储层、事件日志、并发控制。
  • 07 文件导入、全文检索与快照 ProjectCorpus：导入管线、格式识别、FTS5/BM25、不可变 Snapshot。
  • 08 Agent 基础：LLM 如何调用工具 Agent 是什么、PydanticAI 如何工作、本项目装配的唯一 Agent 与 10 个窄工具。
  • 09 模型出口与隐私边界：ModelGateway 凭据阻断、PII 占位符、Privacy SQLite、恢复语义 —— 全项目最值得读的部分。
  • 10 沙箱：LLM 生成的代码在哪里执行 OpenSandbox、digest 锁定、attestation 探测、三步挂载、资源限制。
  • 11 耐久编排：Worker、租约、重试与崩溃恢复 LocalDurableExecutor 全解：原子领取、lease fencing、取消语义、恢复决策。
  • 12 验证门与血缘：让结论可信 ExecutionGate / IntegrityGate / EvidenceGate、Finding 生命周期、Lineage 记录。
  • 13 端到端实操：跑通一次完整分析 启动服务、建项目、导文件、建 Task、看 SSE 事件、读最终答案 —— 把前 12 课串起来。
