Lesson 02 · 给零基础补的最小知识

Python 与 Web 基础：读懂代码需要的最小知识

本课只讲「看懂本仓库代码」必需的 Python 特性和 Web 概念。跳过你已会的部分即可。

1. 类型标注（Type Hints）

DataHarness 要求 Python ≥ 3.12（pyproject.toml:5），代码里大量使用类型标注。看一个真实例子 —— api/services.py 里方法的签名：

# src/dataharness/api/services.py:148
def get_project(self, project_id: str) -> Any:

含义：project_id 参数是 str 类型，返回值是 Any。类型标注不影响运行，它给人和工具（pyright/mypy）读。本仓库配置了 pyright 检查（pyproject.toml:53-56）。

本仓库还会用到的标注语法：

  • X | None —— 可选值（Python 3.10+ 语法），等价于 Optional[X]。例：model: str = "gpt-4o-mini" 里 api_key: str | None = None（config.py:58）。
  • tuple[X, ...] —— 变长元组。例：findings: tuple[Finding, ...]（api/models.py:63）。
  • Callable[[Run], SandboxSpec] —— 函数类型（orchestration/protocols.py:15）。

2. Pydantic BaseModel：带校验的数据类

Pydantic 是本项目的建模基础（依赖声明在 pyproject.toml:12）。它做的事情：声明字段 → 自动校验/转换 → 序列化成 JSON。看 API 请求模型：

# src/dataharness/api/models.py:14-17
class CreateProjectRequest(BaseModel):
    """创建 Project 的最小请求。"""
    name: str = Field(min_length=1, max_length=255)
  • 继承 BaseModel 后，字段自动获得校验：name 必须是 1–255 个字符的字符串。
  • 请求 JSON 不合法时，FastAPI 返回 422；Pydantic 的错误信息就是 RequestValidationError 的来源（第 03 课会看到它被映射成统一错误格式）。

本项目所有模型几乎都带 model_config = ConfigDict(frozen=True)，例如：

# src/dataharness/domain/project.py:43-48
model_config = ConfigDict(frozen=True)
id: ProjectId
name: str
status: ProjectStatus = ProjectStatus.ACTIVE

frozen=True 表示对象创建后不可修改（与 dataclass 的 frozen=True 同理）。要"修改"就创建一个新对象（model_copy(update=...)）。第 05 课会专门讲这种设计的价值。

另一种常见写法是 @dataclass(frozen=True, slots=True)，例如 api/errors.py:8-14 的 ApiError —— 与 Pydantic 的取舍：dataclass 更快、不校验；BaseModel 有校验和序列化能力。

3. async / await：并发的基础

Web 服务器要同时服务很多请求。Python 的方案是 asyncio：单线程内用「事件循环」调度协程。关键词只有三个：

  • async def foo() —— 定义一个协程函数；调用它不会立刻执行，而是返回一个可等待对象。
  • await foo() —— 暂停当前协程，等 foo 完成。等待期间事件循环可以跑别的协程。
  • asyncio.run(main()) —— 创建事件循环并运行顶层协程。

项目里的真实例子 —— FastAPI 路由是 async 的：

# src/dataharness/api/app.py:134-136
@app.get("/healthz")
async def healthz() -> dict[str, str]:
    return {"status": "ok"}

Worker 的循环也是 async（providers/durable/executor.py:110-120）：

async def run_worker(self, stop_event: asyncio.Event, *, idle_sleep_seconds: float = 0.1) -> None:
    while not stop_event.is_set():
        result = await self.run_once()
        if result is None:
            with suppress(TimeoutError):
                await asyncio.wait_for(stop_event.wait(), idle_sleep_seconds)

注意：阻塞调用（SQLite I/O、urllib 请求）不能直接放在 async 函数里，否则会卡住整个事件循环。项目的做法是把同步调用包进线程：看 agent/model.py:79 —— await asyncio.to_thread(self._gateway.complete, ...)，把耗时的模型请求放到线程里执行。

项目用的另一个并发原语

threading.Thread 也出现了 —— 在 launcher.py:131-140，启动器用线程把子进程（Sandbox/API/Worker）的日志输出转发到终端。asyncio 负责进程内的协程调度，subprocess 负责进程间，各司其职。

4. HTTP 与 Web 服务器：请求是怎么变成代码执行的

Web 开发的核心心智模型，一张图讲完：

你的浏览器 / curl │ 发送 HTTP 请求：方法(GET/POST) + URL(/projects) + 头(Header) + 体(Body) ▼ Web 服务器（uvicorn：解析 HTTP 协议，处理网络） ← 本项目的 web 服务器 │ 调用你的应用代码 ▼ FastAPI 应用（路由匹配 → 校验参数 → 调用你的函数） ← 本项目的应用框架 │ ▼ 返回 HTTP 响应：状态码(200/404/500) + JSON 体

uvicorn 是 ASGI 服务器（pyproject.toml:17），FastAPI 是构建在它之上的框架（pyproject.toml:16）。

必须认识的状态码（本项目都会用到）：200 成功、201 创建成功、400 请求不合法、404 资源不存在、422 参数校验失败、500 服务器内部错误。

本项目的完整路由表在 ARCHITECTURE.md:567-589（第 20 节）。例子：

POST /projects                     # 创建 Project
POST /projects/{id}/files          # 导入文件（原始字节，文件名放 X-File-Name 头）
POST /projects/{id}/tasks          # 创建分析任务
GET  /tasks/{id}/events            # 任务事件
GET  /tasks/{id}/answer            # 最终回答

5. JSON：API 的通用语言

HTTP 响应体一般是 JSON。FastAPI + Pydantic 帮你自动完成「Python 对象 → JSON」和「JSON → Python 对象」。

本项目有一个细节值得注意：所有路由都返回 model_dump(mode="json") 后的 dict，而不是依赖 FastAPI 的自动序列化（api/app.py:88-95 的错误处理就是手动构建 JSON）。因为 domain 对象含 datetime 等类型，mode="json" 会统一转成 ISO 字符串，保证格式可控。

6. 环境与依赖管理：uv + pyproject.toml

Python 项目的「配方」写在 pyproject.toml，依赖的精确版本锁定在 uv.lock。安装只用一条命令：

uv sync --locked    # 按 uv.lock 精确安装（--locked 表示不更新锁文件）

运行仓库里的命令：

uv run dataharness check    # 等价于：进入虚拟环境执行 dataharness 命令

命令入口的注册在 pyproject.toml:21-22：

[project.scripts]
dataharness = "dataharness.cli:main"

意思是：执行 dataharness 就等于调用 cli.py 里的 main 函数。第 04 课会解剖这个函数的内部。

练习：在代码里找语法

小测验：frozen=True 的 Pydantic 模型如何"修改"？

查看解析
frozen 模型赋值会抛 ValidationError。所有状态变更都返回新实例，例如 task.py 里的 start()/complete()（第 05 课详讲）。这保证了「旧状态对象永远有效」，是并发安全的基础。

小测验：uvicorn 和 FastAPI 的关系是？

查看解析
分层：uvicorn 处理 TCP/HTTP 协议，把请求交给 FastAPI 应用；FastAPI 负责路由匹配、参数校验、调用你的函数。启动命令 uvicorn.run(create_app(...))（cli.py:108-119）就是「把应用交给服务器」。
