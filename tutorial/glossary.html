核心概念

术语含义在本项目中的位置
DataHarness本项目名：本地优先、云端 LLM 驱动、沙箱隔离执行的数据分析 Agent Harness仓库根目录
Harness「马具」——一种装配、约束和编排第三方组件的框架层，不自己实现通用基础设施自研 Domain/编排，复用 PydanticAI/OpenSandbox
Project长期容器，装一个分析项目的全部文件版本与正式产物domain/project.py
ProjectFile / ProjectFileVersion逻辑文件 / 不可变文件版本（同名字重复导入生成新版本）domain/project.py
ProjectSnapshot创建时固定的文件版本清单，Run 的只读输入视图，创建后不可变domain/project.py
Session绑定单一 Project 的对话上下文；每条用户消息创建一个 Taskdomain/session.py
Task一次用户请求对应的分析任务，必须绑定一个 Projectdomain/task.py
RunTask 的一次执行尝试；终态 Run 永不重开，重试创建新 Rundomain/run.py
AnalysisStep一次独立的代码/SQL 执行，失败后重试创建新 Stepdomain/step.py
FindingAgent 提交的候选结论（FindingCandidate），由 Host 验证门提升为正式 Findingdomain/finding.py
Dataset / Artifact正式发布的派生数据 / 展示产物（图表等），发布后不可变domain/artifact.py
Lineage血缘：资源之间的 source→target 引用边（含 hash）domain/lineage.py
Snapshot（目录层）沙箱内只读挂载的 /project 视图worker.py 挂载解析

架构与安全

术语含义
Host（可信侧）运行 DataHarness 的本机进程：FastAPI、Worker、Runtime SQLite、隐私映射
Sandbox（不可信侧）执行 LLM 生成代码的隔离容器，默认断网、只读挂载 Snapshot
Runtime SQLiteTask/Run/Step 状态、事件、队列、lease 的事实来源（runtime-data/runtime.db）
Privacy SQLite每 Task 独立的 PII 占位映射库（runtime-data/privacy/{task_id}.db）
ModelGateway所有云模型请求的唯一出口：凭据阻断 + PII 占位 + 审计
PlaceholderStorePII 占位符与原文的映射存储（仅存于 Privacy SQLite）
Lease / lease_epochWorker 领取 Run 后持有的「租约」；epoch 是防呆令牌（fencing token）
CASCompare-And-Swap：按 row_version 条件更新，并发冲突即失败
Attestation创建/重连沙箱后用运行时探测核验实际配置（digest/网络/权限/挂载），不符即 fail closed
digest 锁定镜像引用必须是 name@sha256:64位hex，禁止 latest 标签
fail closed条件不满足时宁可失败，也不静默降级
CheckpointAgent 消息历史与状态的持久化快照（Workspace 文件 + Runtime 元数据）
Compaction上下文超预算时用模型总结压缩历史
Verification GateExecutionGate / IntegrityGate / EvidenceGate 三个 Host 验证门
FTS5 / BM25SQLite 全文检索虚拟表 / 相关度排序算法
SSEServer-Sent Events：服务器单向推送事件流（/tasks/{id}/events/stream）
UoWUnitOfWork：一个事务包裹多个仓储操作，全部成功或全部回滚
PydanticAI本项目使用的 Agent 框架（工具调用、结构化输出、UsageLimits）
FunctionModelPydanticAI 的模型适配接口；本项目用它将 ModelGateway 接进 Agent
OpenSandbox独立的沙箱平台服务（127.0.0.1:18080，Docker backend）

常用缩写

  • API — Application Programming Interface，程序接口；本项目即 FastAPI HTTP 控制面
  • LLM — Large Language Model，大语言模型（本项目中的"云模型"）
  • Agent — 能调用工具、自主规划执行步骤的 LLM 程序
  • PII — Personally Identifiable Information，个人可识别信息（邮箱、手机号、证件号等）
  • FTS — Full-Text Search，全文检索
  • SSE — 见上
  • WAL — Write-Ahead Logging，SQLite 预写日志模式（并发读写友好）
  • OTel — OpenTelemetry，可观测性标准
  • DTO — Data Transfer Object，跨边界传输的数据结构（本项目 api/models.py）
  • TOML — 配置文件格式（dataharness.example.toml）
